## Szablon MADR

```markdown
# NNNN. Tytuł decyzji

- Status: Proponowana | Przyjęta | Odrzucona | Zastąpiona przez NNNN
- Data: RRRR-MM-DD

## Kontekst

Jaki problem rozwiązujemy i jakie są ograniczenia.

## Decyzja

Co wybieramy i dlaczego.

## Rozważane opcje

- Opcja A: zalety, wady
- Opcja B: zalety, wady

## Konsekwencje

Co się zmienia na plus i na minus.
```
